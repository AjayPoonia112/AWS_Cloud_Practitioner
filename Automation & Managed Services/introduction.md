# Automation & Managed Services

## Learning Objectives

- Understand the benefits of automation in cloud services.
- Learn the uses of Amazon RDS for managed relational databases.
- Learn the uses of Amazon ECS for container orchestration.
- Learn the uses of Amazon EKS for Kubernetes-based container management.
- Explore Amazon DynamoDB for NoSQL database requirements.
- Gain knowledge of AWS Lambda and Function as a Service (FaaS).
- Review Amazon S3 for scalable and durable cloud storage solutions.
